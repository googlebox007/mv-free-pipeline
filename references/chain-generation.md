# 免费链式生成法（突破 4 秒限制的核心）

## 原理
单段免费上限 4 秒。用"末帧续接"把 N 个 4 秒段拼成任意长度的长镜头：每段都是上一段的直接延续，运动连贯。

## 标准操作
1. 该镜 seg1：首帧 = HERO 关键帧，提示词 = 原运动提示词。
2. 该镜 segK（K>1）：从上一段末尾约 0.5s 处抽帧：
   ```bash
   ffmpeg -sseof -0.5 -i clips/S<NN>_seg<K-1>.mp4 -vframes 1 clips/S<NN>_seg<K-1>_lastframe.png
   ```
   该帧作为下一段的 First Frame，提示词 = `The scene continues: <原运动提示词>`。
3. 每镜段数 = ceil(目标时长 / 3.75)。8s→2 段，10s→3 段，12s→3 段。
4. 维护台账 `video_plan.md`：每段 pending / in-flight / done，记录 clip 路径与时间戳。

## 串行纪律（血泪教训）
- **同一时间只允许 1 个在飞分段。**
- 提交/下载前必须 grep 台账**尾部**最新条目，再次确认队列状态（定时任务槽位可能重叠导致读到旧状态，曾有重复提交近失误）。
- 进度报告：cron 每 10 分钟汇报 `done n/N`；全 done 后立即 `cron.update` 停用该任务。

## 逐段 QC（不合格记回 pending，注明原因）
- 时长 ≈3.75s，480P，无破坏性水印（免费档实测无水印，仍要看四角）。
- 无烧录字幕/乱码（S25 曾出现乱码字幕整段废弃）。
- 人物服装/发型与首帧一致；运动符合提示词；无严重畸变。
- 接缝检查：起帧与上一段末帧视觉一致。

## 提示词技巧
- 角色圣经：每张关键帧提示词原样复用一段人物描述（背影/侧面为主可大幅降低崩脸率；正脸只给极少镜头）。
- 风格圣经：每提示词追加画幅、调色、颗粒、"No text, no watermark, no logo"。
- 选帧用 80% 原则：只修明确失败点，不反复刷完美。
